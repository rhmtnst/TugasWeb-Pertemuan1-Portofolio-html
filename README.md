## Deskripsi

Project ini merupakan tugas rutin Pertemuan 1 berupa pembuatan landing page pribadi menggunakan HTML.

Landing page berisi profil pribadi, pengalaman, informasi kontak, serta form untuk mengirim pesan.

## Teknologi

- HTML5
- CSS3

## Fitur dan Struktur

Landing page menggunakan struktur HTML5 semantic, yaitu:

- `header` — menampilkan foto profil, nama, dan status sebagai mahasiswa.
- `nav` — navigasi menuju bagian Tentang, Pengalaman, dan Kontak.
- `main` — berisi konten utama halaman.
- `section` — digunakan untuk bagian Tentang Saya, Pengalaman, dan Kontak.
- `article` — digunakan untuk menampilkan pengalaman secara terpisah.
- `aside` — menampilkan motto hidup.
- `footer` — menampilkan informasi hak cipta.

## Konten Halaman

### Tentang Saya

Menampilkan informasi singkat mengenai profil dan ketertarikan dalam bidang data dan sosial media.

### Pengalaman

Terdapat dua pengalaman yang ditampilkan:

1. Bright National Summit
2. Relawan Pascabanjir

Setiap pengalaman dilengkapi gambar, deskripsi, daftar aktivitas, serta informasi waktu menggunakan elemen `time`.

### Kontak

Bagian kontak berisi:

- Email
- GitHub
- Instagram

Selain itu terdapat form kontak dengan beberapa jenis input:

- Text
- Email
- Date
- Color
- Range
- Textarea
